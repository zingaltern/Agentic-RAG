# 报销制度（Demo 知识库：docs 库）

## 报销标准

| 类别 | 标准 | 说明 |
|---|---|---|
| 交通费 | 实报实销 | 凭发票报销 |
| 住宿费 | 一线城市 500 元/晚，其他城市 350 元/晚 | 上限标准 |
| 餐饮费 | 一线城市 150 元/天，其他城市 100 元/天 | 出差期间 |
| 办公用品 | 单笔 500 元以下 | 需附采购清单 |
| 培训费 | 每年 2000 元额度 | 部门内培训 |

## 报销时限

- 出差结束后 3 个工作日内于 OA 系统提交发票。
- 普通费用报销：财务审核通过后 5 个工作日内打款至工资卡。
- 发票丢失：需补开或出具情况说明，经部门负责人签字。

## 报销流程

1. 员工在 OA 填写报销单并上传发票。
2. 部门负责人审批。
3. 财务审核发票合规性。
4. 打款至员工工资卡。

## 常见问题

- 电子发票：支持 PDF 与截图上传。
- 打车费：凭行程单实报实销，单日上限 200 元。
- 报销被驳回：常见原因为发票抬头错误、超出标准、缺少明细。
- 紧急报销：可联系财务加急，1 个工作日内处理。
