## 二、修改内容（仅动 resume-java.tex 第 185–195 行的 RAG 项目块，其余不动；日期 2026.04--至今 保留）

```latex
{\entryheadfont Agentic RAG 智能知识库系统}（\textnormal{Python · FastAPI · Chroma · BM25/BGE · DeepSeek · Vue3/Electron}）\dateright{2026.04 -- 至今}

项目描述：面向企业制度与技术文档的自研检索增强问答系统：多格式文档异步入库（解析、清洗去重、父子分块）后经 BM25 + 向量混合检索与反思循环迭代改写，生成带引用的可溯源答案；支持多知识库、多轮对话与联网检索，Vue3 + Electron 双端交付。

\begin{itemize}
  \item \textbf{插件化架构：}以 11 个抽象接口 + 策略模式注册表编排 12 个组件实现，重排 / 评测 / 改写 / LLM 每模块均配“增强 + 兜底”双实现并可配置热切换、故障自动降级；SystemConfig 集中配置 + fail-fast 启动校验，新增组件零侵入。
  \item \textbf{混合检索与多级缓存：}BM25 与 BGE 向量双路线程池并行召回（端到端延迟由两路求和降为取最大值），RRF（k=60）融合 + CrossEncoder 精排；设计 BM25 索引 / 查询结果 / 父块三级缓存（mutation\_epoch 失效校验 + LRU/TTL），检索 filters 全链路贯穿实现多知识库物理隔离。
  \item \textbf{反思循环与稳定性：}检索不达标时 LLM 改写 query（代词消解、多变体 RRF 再融合），失败逐级回退规则改写；每轮 query 强制与上轮不同，按“去停用词 / BM25 单路 / 向量单路”换路重检；30s 全局 + 10s 检索双层超时预算熔断、低分查询绝望短路，多 LLM 候选独立熔断（3 次失败 / 60s 冷却）。
  \item \textbf{评测驱动与安全治理：}忠实度评估 + 引文对齐双门禁抑制幻觉，入库侧提示注入扫描 / 内容审核 / simhash 去重，查询侧 IP 限速 + 并发信号量；437 项单测（覆盖率 91\%）+ 三层评测回归（验证集 107/107 全绿、外部 CMRC 2018 基准 160 条 Hit@1 98\%），驱动忠实度由 0\% 提升至 56\%。
\end{itemize}
```
